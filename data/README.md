# Data Directory Documentation

This directory contains the phenotypic records, marker index manifests, population structure assignments, and cross-validation partition tables accompanying the manuscript:

> **"Sparse Multi-Trait Genomic Prediction in the 3,000 Rice Genomes: An Empirical Evaluation of Linear Baselines, Auxiliary Helper Phenotypes, and Neural Multi-Task Strategies"**

The purpose of this documentation is to provide an independent researcher with complete technical descriptions of the datasets, their biological origins, their variable schemas, and the experimental framework required to reproduce the reported genomic prediction experiments.

## 2. Detailed Dataset Descriptions

### 2.1 `canonical_phenotypes.csv`
- **Path:** `data/canonical_phenotypes.csv`
- **Dimensions:** 3,024 rows × 11 columns
- **Primary Key:** `FID` / `IID` (identical 1-to-1 accession codes matching PLINK `.fam` coordinates).
- **Missing Value Convention:** Standard IEEE NaN / empty CSV string (`,,`). No artificial negative sentinel values (e.g., `-999`) are used.
- **Description:** The harmonized accession-by-trait phenotype matrix for the 3,024 accessions. It contains four densely observed grain morphology helper traits (H1–H4; 79.76% observed) and five sparsely observed abiotic and biotic stress resistance target traits (T1–T5; 17.76%–20.50% observed).
- **Derived Trait Notice:** Trait `H4_Grain_Length_Width_Ratio` is an algebraically derived index computed directly as the ratio of grain length to grain width ($H_4 = H_2 / H_3$). In the upstream supplementary table MMC4, the column labeled `Ratio_of_grain_length_to_grain_width` erroneously duplicated the `Grain_width` values; `canonical_phenotypes.csv` resolves this discrepancy by explicitly computing the true mathematical quotient.

#### Column Schema
| Column Name | Data Type | Null Count (%) | Measurement Unit | Value Range (Min – Max) | Meaning / Description |
|---|---|---:|---|---|---|
| `FID` | `object` (str) | 0 (0.00%) | Identifier | `B001` – `B3024` | Family ID coordinate in PLINK binary files |
| `IID` | `object` (str) | 0 (0.00%) | Identifier | `B001` – `B3024` | Individual ID coordinate in PLINK binary files (`FID == IID`) |
| `H1_Thousand_Grain_Weight` | `float64` | 612 (20.24%) | Grams (g) | 8.66 – 46.27 | Weight of 1,000 filled grains under non-stress conditions |
| `H2_Grain_Length` | `float64` | 612 (20.24%) | Millimeters (mm) | 5.34 – 11.79 | Mean longitudinal axis length of mature rough rice grain |
| `H3_Grain_Width` | `float64` | 612 (20.24%) | Millimeters (mm) | 1.69 – 4.54 | Mean transverse axis width of mature rough rice grain |
| `H4_Grain_Length_Width_Ratio` | `float64` | 612 (20.24%) | Ratio (dimensionless) | 1.48 – 4.15 | Ratio of grain length to width ($H_4 = H_2 / H_3$) |
| `T1_Drought_Resistance_Grade` | `float64` | 2,487 (82.24%) | Standard Grade (1–9) | 2.22 – 6.61 | Visual evaluation score under drought stress (1 = resistant, 9 = susceptible) |
| `T2_Heat_Survival_Rate` | `float64` | 2,404 (79.50%) | Percentage (%) | 0.00 – 100.00 | Seedling survival percentage following high-temperature treatment |

| `T5_Sheath_Blight_Relative_Lesion_Height` | `float64` | 2,461 (81.38%) | Ratio (0.0–1.0) | 0.06 – 1.00 | Ratio of sheath blight lesion height to total plant height |

#### Accession Phenotypic Coverage Breakdown
- **1,290 accessions:** Observed for both helper traits (H1–H4) and at least one target trait (T1–T5).
- **1,122 accessions:** Observed for helper traits only; zero target observations.
- **152 accessions:** Observed for at least one target trait; zero helper observations.
- **460 accessions:** Genotype-only accessions; neither helper nor target observations recorded.
- **Total evaluation frame:** Exactly 1,442 unique accessions have $\ge 1$ naturally observed target trait.

### 2.3 `population_cluster_assignments.csv`
- **Path:** `data/population_cluster_assignments.csv`
- **Dimensions:** 3,024 rows × 2 columns
- **Primary Key:** `accession_id`
- **Missing Value Convention:** Zero missing values.
- **Description:** Fixed, unsupervised cohort reference cluster assignments ($K = 4$) derived from the top 20 principal components of the 10,000-marker genotype panel across all 3,024 accessions:
  ```python
  imputer = MarkerMeanImputer()
  X_imp = imputer.fit_transform(X_10k_raw)
  pcs = PCA(n_components=20, random_state=42).fit_transform(X_imp)
  clusters = KMeans(n_clusters=4, random_state=42, n_init=20).fit_predict(pcs)
  ```
  These cluster assignments serve as reference targets for Hungarian linear sum assignment across cross-validation folds, Group-DRO optimization partitions, and leave-one-genotype-cluster-out (LOGCO) generalization tests.

#### Column Schema
| Column Name | Data Type | Null Count | Description |
|---|---|---:|---|
| `accession_id` | `object` (str) | 0 | Unique accession identifier (`B001` to `B3024`) |
| `reference_cluster_id` | `int64` | 0 | Unsupervised reference cluster ID: `0`, `1`, `2`, or `3` |

- **Cluster 1:** 217 accessions (7.18%)
- **Cluster 2:** 1,832 accessions (60.58%)
- **Cluster 3:** 357 accessions (11.81%)

## 4. Experimental Design Summary

To correctly interpret the data files and cross-validation indicators, the experimental setup is summarized below:

- **Cohort Size ($N$):** 3,024 sequenced rice accessions (*Oryza sativa* L.).
- **Full Genomic Panel ($M_{\text{full}}$):** 404,388 biallelic SNPs mapped to the *Nipponbare* IRGSP-1.0 assembly.
- **Dimensionality Reduction Grid ($m$):** 10,000 index-spaced markers extracted across the ordered panel (`selected_10000_marker_ids.tsv`).
- **Feature Pipeline (Ridge and Neural MTL):** Strictly in-fold marker mean imputation (`MarkerMeanImputer`), standard scaling (`StandardScaler(ddof=0)`), and principal component analysis (`PCA(n_components=120)`).
- **Kernel Baseline (GBLUP):** Full 404,388-marker panel utilized to construct the VanRaden genomic relationship matrix strictly within each outer training fold.
- **Repeated Nested Cross-Validation:** 3 complete repeats of 5-fold cross-validation ($3 \times 5 = 15$ folds total), initialized with seeds `42`, `101`, and `777`.
- **Primary Target Masking Protocol:** 40% retention of naturally observed target training labels (60% masked; ~172–198 observed training labels per target per fold; 8,709 total evaluated test observations). Helper traits (H1–H4) are 100% available in training folds.
- **Subpopulation Structure:** 4 unsupervised clusters derived from genotype principal components (`population_cluster_assignments.csv`). In-fold clusters are aligned to cohort reference centroids using the Hungarian algorithm (`scipy.optimize.linear_sum_assignment`).

```
                                                                           └── factorial_ablation_...csv
```

### 5.1 Pipeline Roles
1. **`pipeline_config.json`:** Global configuration defining random seeds (`[42, 101, 777]`), CV parameters (`n_repeats=3`, `n_splits=5`, `primary_obs_ratio=0.40`), PCA components (`120`), trait names, and model inventories.
2. **`core_engine.py`:** Computational library providing mathematical functions for in-fold preprocessing, GBLUP, RidgeCV, Helper Stacking, PyTorch neural multi-task learning models, Hungarian cluster alignment, and statistical resampling routines.
3. **`step_master_pipeline.py`:** Authoritative end-to-end master orchestrator. Loads `data/canonical_phenotypes.csv` and the PLINK genotypes, runs the 15-fold cross-validation, executes all nine predictive models, performs factorial ablations, and writes evaluation outputs to `artifacts/`.
